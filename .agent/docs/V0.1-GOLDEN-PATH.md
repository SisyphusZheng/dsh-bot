# v0.1 黄金路径验收（S0–S11）

本文件是 dsh-bot v0.1 唯一的产品验收主线。**所有门禁必须在真实安装后的产品包内执行**；开发目录、Chromium、mock 只算组件证据。

## 前置

- 产物：`dsh-bot.app` + `whalegirlbot-0.1.0-mac-arm64-unsigned.dmg`（内部验收包）
- 环境：macOS Apple Silicon、隔离测试账户、受控测试目录
- 记录：每步保存操作、日志、截图、结构化结果、PASS/FAIL/CONDITION、复现命令
- 禁止：修改用户真实私人数据；触碰或复用主 DSH `~/.dsh`

## 判定

- 全部 S0–S11 有真实包内证据 → 对应 Gate 可申请 `MVP PASS`
- 仅因签名/公证/真人 TCC 无法完成 → `MVP PASS WITH CONDITION`，并列出精确人工步骤
- 未覆盖能力 → `DEFERRED`，写明版本与理由
- 任一核心步骤失败 → `BLOCKED` 或 `FAIL`，不得降级门禁
