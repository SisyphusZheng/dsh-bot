# 桌宠交互界面

[English](README.md) | 中文

桌宠和气泡分别使用独立 Electron 窗口。透明气泡窗口按渲染后的卡片高度调整，并受配置的最大高度限制；短提示保持紧凑。问题正文与完整选项说明共用可用键盘滚动的内容区，显示滚动条和溢出提示；答复控件留在独立的固定底栏。双击对话气泡或桌宠可打开 DSH。

对话和待处理请求详情支持 CommonMark 标题、强调、列表、引用和代码。渲染创建 DOM 元素，不执行 HTML、不加载外部媒体，也不允许模型控制导航。完整回复保留在可滚动气泡和 DSH 中；界面不截断模型输出。

Host 人格提示要求普通回复简短、汇报先给结果，同时允许按需详细说明。这是模型指令，不是保证生效的字数上限。审批、失败和必要操作详情必须明确保留。

开始收音后，即使 ASR 尚未返回文本，也显示“取消录音”。它只丢弃对应录音；停止 Agent 任务是独立操作。待处理审批和问答优先于临时录音提示。

构建后运行 `node product/tools/smoke-pet-ui.mjs`，生成界面截图并检查布局和交互。Playwright 浏览器不可用时，`DSH_CHROMIUM_EXECUTABLE` 可指定已安装的 Chromium。`product/tools/verify-local.sh` 包含这项检查、启动测试和已有语音/Host 检查。macOS 物理鼠标行为、麦克风权限和房间声学需要原生验收。

恢复入口位于右键菜单和任务失败气泡。选择模式不会执行任务：下一张卡片先展示原指令和副作用警告，再单独确认。新任务或待处理审批会使旧草稿失效。带可见操作按钮的提示会接收鼠标交互。
