## 已验证的行为变化

- 问题正文和完整选项说明共用滚动区，超过高度时显示滚动提示；答复控件固定在有分隔线的底栏。测试从短气泡切换到超长选项、滚动到底、选择第二项并提交，使用会实际缩放的窗口夹具。内容区点击后可获得键盘焦点，不自动抢主窗口焦点。
- 常听普通输入先显示“我听到（尚未发送）”，支持确认、修改和丢弃，30 秒过期且只能确认一次。可说“确认发送”或“取消输入”。未确认内容不进入 Agent 队列，也不会凭普通 VAD/非控制词打断播报。按住／切换模式保留主动收音直接提交；模式切换结束旧录音，不刷新页面或断开媒体。配置的称呼唤醒短语仍生效，预览不会提前延长唤醒窗口。
- 常听中的“别说了”仍直接停播；批准和停止任务分别要求“确认允许一次”和“确认停止任务”。拒绝保持可用。无审批时“是”等短回复仍是聊天输入，不被审批规则吞掉。它没有增加声纹、置信度或自动说话人识别能力；精确控制词仍有被误识别的可能。
- 语音已连接时，Worker 从鉴权接口读取首位待处理交互，每项审批或问答播报一次，包括主窗口发起的任务。审批不念私人路径和命令；问题和选项名称限制长度，回答仍在气泡完成。关闭语音时不会偷偷开启麦克风或播放提示。
- TTS 接入 Pipecat 自带的 Markdown 过滤器，Provider 夹具实际收到的文本没有 Markdown 星号；会话原文和可视 Markdown 保留。
