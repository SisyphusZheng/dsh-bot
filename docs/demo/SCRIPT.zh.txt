# Nisse / dsh-bot 演示视频脚本

目标：GitHub README 首屏嵌入，90 秒内让面试官看懂“桌面语音 Agent”的独特定位。
形式：屏幕录制 + 字幕 + 中文旁白；另出 15–20 秒 GIF 作为 README 首屏自动播放。

## 一、要讲清楚的三件事

1. **它不是聊天框**：Agent 住在桌面上，有桌宠、气泡、声音和系统入口。
2. **它真的能做事，但有边界**：执行前审批，允许一次/拒绝/始终允许，语音和点击共享同一状态。
3. **它有记忆，也能被打断**：跨会话记忆、停止播报 vs 停止任务、打断后继续。

不要按功能表逐个点；用一条“让它写文件 → 打断 → 再问记忆”的主线。

## 二、录制前置条件

- 使用最新 Mac 候选（当前 `f801a59b`），先确认：
  - 气泡在 dsh-bot 自己的 DSH 主窗口上方也可见；
  - 语音审批“我允许一次”能直接批准，不再生成新任务；
  - 长回复气泡贴着桌宠，不跑到屏幕边缘。
- 使用**隔离 demo profile**（`--user-data-dir=/tmp/nisse-demo` 或专用 demo 用户），不要使用个人真实记忆库。
- 预置假数据：
  - 桌面 `today.md`（允许覆盖）；
  - 一段假的个人偏好：例如“我喜欢浅烘美式，不加糖”；
  - 一个工作区外的写入目标，用来触发审批。
- 清理画面：
  - 关闭通知、微信、邮箱、浏览器个人标签页；
  - 隐藏真实 API Key、聊天记录、文件路径中的用户名；
  - 使用干净桌面背景和单一显示器。
- 录制规格：1920×1080 或 2560×1440，30fps，H.264；旁白单独用麦克风录，后期混入。

## 三、90 秒分镜与旁白

### 00:00–00:06 冷开场

画面：桌面 + 桌宠，气泡轻轻出现。

旁白：
> 这不是又一个聊天框。它住在我桌面上，能听、能做，也有记忆。

字幕：`桌面上的语音 Agent / 不是聊天框里的 Agent`

### 00:06–00:26 语音任务 + 审批

画面：
- 按住 Option，说：“帮我在桌面新建 today.md，写三件今天最重要的事。”
- 气泡显示“我听到（已提交）”，Agent 开始执行。
- 弹出审批：“Nisse 想在工作区外运行命令 / 查看详情 / 始终允许此操作 / 允许一次 / 拒绝”。
- 说：“我允许一次。”
- 文件创建成功，快速展示 `today.md` 内容。

旁白：
> 它真的会动文件、跑命令。但凡是工作区外的副作用，都会先停在我面前，等我批准。

字幕：`真实执行 + 审批门闩 / 允许一次只生效一次`

### 00:26–00:40 打断

画面：
- 让它继续读一段较长的结果。
- 播报中，说：“停一下。”
- 播报停止，气泡回执“已停止播报；没有请求取消任务。”
- 再说：“继续。”

旁白：
> 打断只停声音，不粗暴地杀掉任务。停止播报和停止任务，是两件事。

字幕：`可打断 / 停播报 ≠ 停任务`

### 00:40–00:56 记忆

画面：
- 问：“还记得我上次说我咖啡喜欢怎么喝吗？”
- 回答：“浅烘美式，不加糖。”
- 画面角落标注“跨会话记忆（Hindsight）”。

旁白：
> 换个会话，它还记得。长期记忆不是把聊天记录塞回上下文，而是按需召回。

字幕：`Hindsight 长期记忆 / 跨会话召回`

### 00:56–01:12 语音选择题（可选但加分）

画面：
- 说：“给我三个周末方案，用选项让我选。”
- 气泡出现 3 个长选项，完整可滚动，底栏固定。
- 说：“第二个。”
- 选项被选中并提交。

旁白：
> 语音不只是聊天：结构化提问也能用“第几个”来回答。

字幕：`语音也能回答选择题 / 长选项不裁切`

### 01:12–01:22 桌面交互

画面：
- 拖动桌宠；
- 双击桌宠打开主窗口；
- 点 Dock 图标；
- 右键桌宠 → 退出。

旁白：
> 它还是一个真正的 macOS 桌面应用：Dock、菜单栏、窗口、退出，都按桌面习惯来。

### 01:22–01:30 收尾

画面：终端快速闪过 `accept-macos.sh ... PASS`，切到 GitHub 页面/项目名。

旁白：
> Nisse，一个住在桌面上的语音 Agent。代码、验收和边界都在 GitHub。

字幕：`Nisse / dsh-bot · github.com/SisyphusZheng/dsh-bot`

## 五、旁白录制提示

- 语速比平时慢 10%，每句之间留 0.3–0.5 秒，方便剪辑。
- 不要念“接下来我们展示”；直接说用户价值。
- 不要在旁白里说“完全生产可用/已公证”——当前是 beta，面试里诚实比吹嘘加分。
- 录音环境安静，使用防喷罩；后期做轻降噪，保留桌面音效。

## 八、面试版一句话

> 我做的不是一个聊天机器人，而是一个桌面语音 Agent：它用 DSH 作为唯一 Agent Runtime，用 Pipecat 做实时语音，用 Hindsight 做长期记忆；副作用操作必须审批，打断只停播报不停任务。工程上最难的，是把实时语音、审批安全、桌面窗口层级和 Mac 打包验收做成一个可复现的闭环。
