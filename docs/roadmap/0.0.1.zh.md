# 0.0.1：现有功能稳定化

状态：已批准、待本地执行。入口为 [本地执行计划](LOCAL-0.0.1.zh.md)；当前事实与证据限制见 [基线](baseline.json)。本版将当前 beta 稳定下来，不接入 DS-Bot，不交付完整 CUA，不替换桌宠或语音架构。

## 功能保留清单

欢迎语、麦克风按钮与音量反馈、hold/toggle/always、Option 全局手势、离线唤醒、人格、皮肤、拖动与双击、引导、任务反馈、审批、单选/多选/文本问答、DSH 工具、Hindsight 和已有配置迁移均保留。离线唤醒不等于本地 ASR，常听不承诺声纹识别，键鼠接管停止不宣传为可恢复暂停。

## 发布检查

| 检查 | 必须证明 |
|---|---|
| G1 | Desktop 生产构建与新 DMG 身份匹配；不存在裸 ESM Client 导致的 web boot 失败 |
| G2 | Session、文件/命令工具、审批、单选/多选/文本问答在真实 Host 与桌宠中闭环 |
| G3 | 真实 Provider 连续语音、欢迎语、输入静音、打断、重连；无用户未要求的任务中止 |
| G4 | 原生 Hindsight 写入、语义检索、跨 Session、退出后重启召回，数据不丢失 |
| G5 | 按设置类别更新，生命周期、隔离 HOME、凭据与旧配置恢复正确 |
| G6 | 本地接口鉴权、Origin、日志脱敏与工具审批保持有效 |
| G7 | 安装形态的启动、同 Bot 导航、退出和重启通过；真实 TCC/音频另有人工证据 |

未验证项目保留实际阻塞状态。G3 的物理声学测试或真实 Provider 不通过时，不能发布稳定版；可交付明确列出限制的 beta 候选。构建成功不代表完成产品验收。

## 不进入本版

DS-Bot/Main Bot 整合、完整 CUA、Coopanion 级动作重做、本地 ASR/神经 TTS、多引擎和插件双交付进入各自后续版本。本版可以修复桌宠现有交互缺陷，但不得通过删功能或改变整体视觉方案缩小验收范围。
