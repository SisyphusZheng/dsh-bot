# 0.0.1：现有功能稳定化

状态：已批准、待本地执行。入口为 [本地执行计划](LOCAL-0.0.1.zh.md)；当前事实与证据限制见 [基线](baseline.json)。本版将当前 beta 稳定下来，不接入 DS-Bot，不交付完整 CUA，不替换桌宠或语音架构。

## 发布检查

| 检查 | 必须证明 |
|---|---|
| G1 | Desktop 生产构建与新 DMG 身份匹配；不存在裸 ESM Client 导致的 web boot 失败 |
| G2 | Session、文件/命令工具、审批、单选/多选/文本问答在真实 Host 与桌宠中闭环 |
| G3 | 真实 Provider 连续语音、欢迎语、输入静音、打断、重连；无用户未要求的任务中止 |
| G4 | 原生 Hindsight 写入、语义检索、跨 Session、退出后重启召回，数据不丢失 |
| G5 | 按设置类别更新，生命周期、隔离 HOME、凭据与旧配置恢复正确；历史主 DSH Profile 残留按清单检查、备份及处理 |
| G6 | 本地接口鉴权、Origin、完整诊断日志脱敏与审批有效；riskRegister 每项有明确接受范围、修复要求或延期版本，不能仅沿用 PR #11 的旧描述 |
| G7 | 安装形态的启动、同 Bot 导航、退出和重启通过；真实 TCC/音频另有人工证据 |

未验证项目保留实际阻塞状态。G3 的物理声学测试或真实 Provider 不通过时，不能发布稳定版；可交付明确列出限制的 beta 候选。构建成功不代表完成产品验收。

代码冻结：诊断/连接、设置范围、安全默认及必要的发布元数据完成后冻结源码，之后只允许验收发现的局部修复；每次修复形成新候选并重跑受影响检查。产物冻结：自动打包验收与真实声学验收绑定同一个 DMG SHA-256 和 app.asar；任何重新构建都重新建立产物身份，不得沿用旧产物结果。

Apple Developer ID 签名与公证为 DEFERRED，目标 0.1.0 扩大分发阶段；0.0.1 仅作为个人内部版，必须实际验证系统允许的首次打开流程并明确提示未公证，不能要求关闭 Gatekeeper。体积/冷启动不是 DEFERRED 的免责项：使用同一 Mac、配置和缓存策略记录 beta 基线与候选，启动至少三次取中位数，先固定误差预算，超预算不得默认为通过。
