# 0.0.3：桌宠陪伴体验与本地发声

状态：已批准、未开始；依赖 0.0.2。体验参考 Coopanion，代码与素材分别核实许可；保留当前角色、皮肤和全部有效交互，不用整体换皮代替体验改进。

## 前后变化与工作项

| ID | 当前 → 目标 | 实现与验收 |
|---|---|---|
| V003-01 | 独立状态动画 → 协调的动作系统 | 定义待机、倾听、思考、说话、抚摸、拖动、落地、任务和错误的优先级、打断及恢复；连续快速输入不锁死、不反复重播开头 |
| V003-02 | 基础拖动与悬停 → 丰富触碰反馈 | 增加可控的抚摸、拖拽、落地、视线和表情；保留双击打开同 Bot；区分拖动、单击与双击，不误触审批 |
| V003-03 | 气泡逐项显示 → 稳定队列与过渡 | 审批/问答优先，状态与普通对话协调；展示时长有上限，跟随宠物并避开屏幕边缘；不放无任务依据的固定按钮 |
| V003-04 | 仅云端自然播报 → 可选 macOS 本地 TTS | 使用系统可用语音，增加试听、停止、声音选择与云端失败提示；复用现有播放/取消状态，避免双路同时说话 |
| V003-05 | 配置术语分散 → 三步首启引导 | 连接主模型、选择语音方式、试说一句；分别验证输入与输出，错误有下一步；不要求用户理解内部进程名 |
| V003-06 | 下载模型与安装体积缺少明确反馈 → 可管理资源 | 显示可选模型大小、版本、哈希、下载与移除；删除模型不删记忆，默认安装包不携带所有可选模型 |
| V003-07 | 本地 ASR/神经 TTS 未定 → 有实测依据的选择 | 比较中文准确度、首响、内存/CPU、长句、授权和 ARM64 打包；达到预算才作为按需选项交付，否则明确 DEFERRED；本版最低承诺为系统 TTS |
| V003-08 | 手感缺少连续验证 → 真实交互与声学验收 | 测试多屏、缩放、鼠标穿透、快速拖动、连点、长对话、外放和耳机；录屏标注实际构建，不用静态效果图代替验收 |

系统本地 TTS 只解决输出，不承诺整个助手离线。现有 Pipecat 与云端 ASR/TTS 持续保留；引入本地语音不得取消原有的打断、欢迎语、麦克风显示和任务播报。
