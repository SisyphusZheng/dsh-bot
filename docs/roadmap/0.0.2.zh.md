# 0.0.2：DS-Bot 适配、共享个人记忆与 CUA

状态：已批准、未开始；依赖 0.0.1 稳定化。实现遵循 [接入决定](../decisions/agent-integration.zh.md)。本版选择性接入并适配社区 DS-Bot，不整套替换现有产品，不运行第二套主 Agent Runtime。

## 用户行为变化

0.0.1 的桌宠通过 Bridge 使用自己的 Bot Agent；0.0.2 的桌宠成为所选 DS-Bot Main Bot 的桌面与语音入口。语音、主窗口、任务、审批和个人记忆指向明确的 Bot 与会话；Main Bot 可调用接好的 macOS CUA。仅复制聊天文字不算接入完成。

## 最低任务集

- 找到并切换 Finder/文本编辑应用，读取窗口状态，在测试文档输入文本并检查结果。
- 在测试目录整理文件，必要时走文件或命令工具；不要求所有任务都用鼠标完成。
- 语音启动任务，在主窗口继续查看与答复审批；气泡过期按钮不能决定其他请求。
- 操作中人工接管、撤销权限、关闭目标窗口和断开语音，各自只影响所属操作。
- 在新的 Session 和重启后召回明确保存的个人事实，同时验证群聊隔离。

有能力的文件和浏览器工具继续使用；CUA 补齐桌面界面操作。正式交付前不把“命令打开应用”解释成完整 GUI 操作验收。
